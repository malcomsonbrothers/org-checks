# Org lists for scripts/check-binaries.sh. Data only: extend a list by adding a line. No repository
# can change them; a repository allows a path with an allow row in .binary-allow instead.
#
# Lines (# starts a comment; patterns are matched against the lower-cased file name, or for dir
# against each folder name in the path; * is any run of characters, ? one, [..] a class):
#   about <category> <description>   how a failure in the category is described
#   deny <category> <pattern>        a file name that fails even when it is text or a Git LFS pointer
#   keep <pattern>                   a file name never denied by name (content and size still count)
#   dir <category> <pattern>         a folder name nothing may be committed under
#   magic <category> <hex pattern> <name...>   first bytes (lower-case hex) of a media file
#   icon <pattern>                   a favicon or app icon name (passes when small and an image)
#   icondir <pattern>                a folder whose images are app icons
#   iconext <extension>              an image extension a favicon or app icon may have
#   tokenfile <pattern>              a config file that fails when it holds a literal token

about media image, video or audio (belongs in R2 or the local test corpus)
about image image content (belongs in R2 or the local test corpus)
about 3d 3D, Blender or texture file (keep it in R2 or a project store)
about model model weights or array data (keep them in R2 or a model store)
about archive archive or package (publish it to a registry or R2 instead)
about compiled compiled or object code (build it in CI instead)
about database database file (seed it from SQL or a script instead)
about office office document or PDF (keep it in a document store)
about secret secret, key or state file (keep it in SSM or a secret store, and rotate it if real)
about junk editor, OS or tool junk (delete it and add it to .gitignore)
about dir build output or dependency folder (add it to .gitignore)
about font font (list it in .binary-allow if the repository must ship it)
about lfs Git LFS pointer (keep binaries out of LFS too)
about binary binary content, a NUL byte in the first 8 KB
about size file over 1 MB (list it as allow, or as exempt when generated, in .binary-allow)
